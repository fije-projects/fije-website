Free Chrome extension

Fije Log Explorer for Salesforce

A small tool to find and read Apex debug logs without clicking through Setup one log at a time. We built it for our own projects. If it helps you too, you're welcome to use it.

Add to Chrome

Free · No account · No data collected

What it does

  • Search logsBy user and time window, with status, duration, size and an exception count for each log.
  • Search inside logsType a method, an exception or an Id and see the matching lines.
  • Read them easilyA fast viewer, colour-coded by event type, with clickable record Ids and find-in-log.
  • Trace flagsSee the active ones and switch on or extend logging for a user.
  • Auto-refreshKeeps the list up to date while you re-run a transaction.
  • Several orgsPick which open org to work on. Enhanced Domains are handled automatically.

Privacy

The extension has no backend and collects no data: no sign-up, no analytics. It uses the session of the Salesforce org you're already signed in to and talks only to that org. Logs stay in memory in the tab and are discarded when you close it.

Details and permissions: privacy policy.

How to use it

  1. Add it to Chrome.
  2. Open your Salesforce org in a tab and sign in.
  3. Click the Fije Log Explorer icon: a new tab opens on the most recent logs.

Ideas, bugs or something missing? Feedback is very welcome. And if you're working on a Salesforce project, that's what Fije does.
